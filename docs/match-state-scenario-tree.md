# v1.28 — Match-State Scenario Tree

## Goal

v1.28 expands TactiTwin from a single pre-match comparison into a structured catalog of fictional match-state branches.

The goal is preparation, not forecasting:

> What should the staff already have reviewed if the match reaches a specific minute, score state or numerical state?

Each branch is evaluated by the existing score-state/manpower `Context_What_If` engine. The tree does not assign occurrence probabilities and does not claim that one branch is more likely than another.

## Predefined branches

The initial tree contains seven explicit preparation cases:

| Branch | Minute | Score | Players | Purpose |
| --- | ---: | ---: | ---: | --- |
| Opening neutral | 15 | 0-0 | 11v11 | Validate pre-match assumptions early |
| Second-half neutral | 60 | 0-0 | 11v11 | Prepare a level second half |
| Protect lead | 70 | 1-0 | 11v11 | Review late-game risk while leading |
| Chase game | 70 | 0-1 | 11v11 | Prepare a higher-urgency recovery branch |
| Late draw | 80 | 0-0 | 11v11 | Prepare the protect-vs-push trade-off |
| Numerical superiority | 60 | 0-0 | 11v10 | Prepare the structural 11v10 response |
| Numerical inferiority | 60 | 0-0 | 10v11 | Prepare the structural 10v11 response |

The definitions are code-visible and deterministic rather than generated by a language model.

## Existing engine reuse

For every branch, TactiTwin reuses `TactiTwin_Context_What_If`, which already combines:

- score-state historical behaviour;
- minute-aware recommendations and triggers;
- manpower state;
- historical numerical-state coverage;
- the existing 70/30 score-state/manpower adjustment only when manpower coverage is sufficient;
- Full Matchup Scan risk/opportunity context.

No new branch-specific tactical score formula is introduced in v1.28.

## Stress signature

Each branch exposes a descriptive diagnostic:

`risk_minus_opportunity = branch_risk - branch_opportunity`

The delta is labelled:

- `risk-dominant` when the delta is at least +10;
- `opportunity-dominant` when the delta is at most -10;
- `balanced-pressure` otherwise.

This is a literal comparison between two existing What-if outputs. It is not a new tactical score, probability or recommendation engine.

## Response Matrix reference

The complete v1.27 Tactical Response Matrix is attached once as a shared pre-match reference.

v1.28 deliberately sets:

`state_reranking_applied = false`

The response packages are therefore **not** re-ranked separately for every branch. That step is intentionally deferred until a transparent state-to-response rule can be defined and regression-tested without smuggling coaching assumptions into an opaque combined score.

## Output per branch

Each branch exposes:

- branch ID, bilingual name and purpose;
- phase;
- exact minute/score/player-count hypothesis;
- score-state and manpower-state labels;
- historical risk and opportunity outputs;
- descriptive stress signature;
- evidence coverage, including manpower coverage;
- historical behaviour payload;
- existing Context What-if recommendations;
- existing decision triggers;
- source method metadata.

The tree summary identifies the highest-risk and highest-opportunity branches, counts low-coverage branches and counts branch orientations. These are descriptive summaries only.

## REST

Authenticated WordPress administrators can request:

`GET /wp-json/tactitwin/v1/planning/match-state-scenario-tree`

Parameters:

- `team_id` — required;
- `opponent_id` — required;
- `limit` — 1–10 imported matches used to build team profiles, default 5;
- `lang` — `en` or `es`.

## Method boundaries

v1.28 does not:

- predict which branch will occur;
- assign branch probabilities;
- predict a final score;
- estimate win/draw/loss probability;
- change Full Matchup Scan scores;
- change existing What-if recommendations;
- activate Plan A/B/C;
- re-rank v1.27 Tactical Response Matrix packages by state;
- infer the identity of a dismissed/substituted player;
- infer post-dismissal formation geometry without explicit data.

## Regression guarantees

The v1.28 regression suite verifies:

- all seven predefined branches are produced in stable order;
- score states resolve correctly for leading/trailing/drawing cases;
- 11v10 and 10v11 resolve to numerical superiority/inferiority;
- every branch exposes existing What-if recommendations and the descriptive stress delta;
- ES/EN branch ordering and numeric risk/opportunity outputs are invariant;
- the v1.27 response matrix remains present but explicitly un-re-ranked by state;
- source Full Matchup Scan data is not mutated;
- invalid source scan input is rejected.

## Next direction

v1.28 gives TactiTwin a deterministic scenario tree. A later layer can compare which tactical response package remains robust across several branches, but only with explicit assumptions and separate reporting of observed evidence versus simulated preparation logic.
